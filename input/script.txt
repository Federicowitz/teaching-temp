Spiegazione della funzione parseCSV

Questa è la funzione più importante.

function parseCSV(csvText) {

Riceve una stringa CSV.

const rows = [];

Creo un array vuoto.

Alla fine conterrà tutti gli oggetti.

const cleanText = csvText.trim();

Pulisco il testo togliendo spazi e righe vuote all’inizio e alla fine.

const lines = cleanText.split("\n");

Divido il CSV in righe.

Da questo:

nome,citta,eta
Luca,Roma,18
Giulia,Milano,19

ottengo:

[
  "nome,citta,eta",
  "Luca,Roma,18",
  "Giulia,Milano,19"
]
const firstLine = lines[0];

Prendo la prima riga, cioè quella delle intestazioni.

nome,citta,eta
const headers = firstLine.split(",");

Divido la prima riga in colonne.

Ottengo:

["nome", "citta", "eta"]
for (let i = 1; i < lines.length; i++) {

Ciclo tutte le righe, ma parto da 1.

Perché?

Perché lines[0] è l’intestazione.

Le righe vere dei dati iniziano da lines[1].

const line = lines[i];
const values = line.split(",");

Prendo una riga e la divido in valori.

Esempio:

Luca,Roma,18

diventa:

["Luca", "Roma", "18"]
const row = {};

Creo un oggetto vuoto.

Lo riempirò così:

{
  nome: "Luca",
  citta: "Roma",
  eta: "18"
}
for (let j = 0; j < headers.length; j++) {

Ciclo le colonne.

Uso j perché devo associare:

headers[0] → values[0]
headers[1] → values[1]
headers[2] → values[2]
const header = headers[j].trim();
const value = values[j].trim();

Pulisco sia il nome della colonna sia il valore.

row[header] = value;

Questa è una riga fondamentale.

Se:

header = "nome"
value = "Luca"

allora:

row[header] = value;

equivale a:

row["nome"] = "Luca";

quindi l’oggetto diventa:

{
  nome: "Luca"
}

Poi al giro dopo:

row["citta"] = "Roma";

e poi:

row["eta"] = "18";

Alla fine:

{
  nome: "Luca",
  citta: "Roma",
  eta: "18"
}
rows.push(row);

Aggiungo l’oggetto all’array finale.

return rows;

Restituisco tutti i dati convertiti.
